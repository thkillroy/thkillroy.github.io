MICHI-SHIRUBE の使い方

ブラウザで開くだけで使えます。インストールは要りません。ルートを保存したり、他の人と共有したりする時だけ、アカウント登録が必要です。

今はテスト公開中です（Web 版・無料）。Android アプリ版は開発中で、このページの「Android アプリ版」の説明は、公開後に使えるようになるものです。

1. ルートを作る

  1. 「✏️ 編集」を押して編集モードにします
  2. 地図をタップすると、その場所がポイントとして追加されます。名前とメモを入れられます
  3. 上の検索欄から店名や住所で探して追加することもできます
  4. ポイントを追加する画面で、ピンの色と移動手段（🚗車・🚶徒歩・🚲自転車・📏直線・🚃電車・✈️飛行機）を選べます。最後に選んだ色と移動手段は覚えていて、次のポイント・次のルートでも最初から選ばれています
  5. 地図のピンか、ルートリストの番号を押すと、そのポイントの編集画面が出ます。名前・メモ・ピンの色と、次のポイントまでの区間（移動手段・線の色・線の種類）を変えられます。「保存」で反映、「キャンセル」か画面の外を押すと変えずに閉じます
  6. ルートリストの番号と番号の間の「＋」を押すと、途中に割り込ませられます。ポイントはドラッグで動かせます

ポイントを選ぶと、地図がそのポイントへ動き（倍率はそのまま）、ピンの色の輪で光り、ルートリストもその番号へ動きます。編集モードを切ると、地図をドラッグしてもポイントは動きません。ポイントを押すと、名前とメモが表示されます。

道に沿った線は、道路の情報から作ります。取れるまでは点線の直線で表示され、電波が弱い時などは、取れるまで自動で取り直します。

2. ナビを使う

  1. 「▶ ナビ開始」を押します
  2. 次のポイントの名前・メモ・残り距離が画面上部に出ます
  3. ポイントに近づくと自動で次へ進み、音声で読み上げます
  4. ナビ中は画面が消えないようになります（対応端末のみ）

到着のお知らせ

画面を見ている時ポイントに着くと、画面の下に「到着：ポイント名」「メモ」「次：次のポイント名（最後は「ゴール」）」が出ます。写真があれば右側に小さく出て、押すと大きく見られます。6秒で消えます。押しても消せます
Android アプリ版で、画面を消している時・別のアプリを使っている時ナビ中は「位置情報を使用中」の通知が出ている間、画面を消しても現在地を追い続けます。ポイントに着くと、音声で読み上げ、画面の上に到着の通知が出ます。通知を押すと、アプリのナビ画面に戻ります。ナビを止めると、画面の裏での位置の取得も止まります

ブラウザ版は、画面を消したり別のアプリに切り替えたりすると、現在地の更新が止まります（ブラウザの決まりのため）。

途中から・続きから

  • 続きから：ナビ中は、どこまで進んだかを覚えています。休憩でナビを止めたりアプリを切ったりしても、同じルートでナビを始めると続きから再開します（覚えているのは24時間）
  • 途中から：覚えていない時は、今いる場所から、ルートのどの区間にいるかを調べて、その先のポイントを次にします。それより前のポイントは灰色（通過済み）になります
  • 再開した時は「○番から再開しました ［最初から］」が出ます。①からやり直す時は［最初から］を押します
  • ナビ中にルートリストの番号を押すと、そのポイントを次にできます

「🔄 復路」を押すと、順番が逆になった帰り道のルートになります。移動手段と線の色もそのまま引き継がれます。

3. 固定ポイント

よく行く場所は「固定ポイント」として保存できます。ルートとは別に、地図に常に表示されます。

  • 地図をタップ →「⭐ 固定ポイント」を選んで保存
  • アイコンは51種類。⭐と🚩は色も選べます
  • 「ルート番号を付ける」にチェックすると、そのまま今のルートにも組み込まれます
  • フォルダで整理できます。フォルダ単位で地図から隠すこともできます
  • 写真を1枚付けられます（ログインが必要です）。写真は自動で小さくして保存し、撮影場所などの撮影情報は取り除かれます。ルートのポイントを固定ポイントにする時にも付けられます

無料では、固定ポイントは30個、写真は10枚まで自由に保存できます。Android アプリ版では、広告動画の追加券でそれ以上追加できます（固定ポイントは最大数なし、写真は最大50枚）。詳しくは無料と有料をご覧ください。

4. マイリストの整理

「📂 マイリスト」で、保存したルートと固定ポイントを整理できます。

検索上の「名前で検索」に入力すると、フォルダに関係なく名前が合うものだけが並びます
並び替え自分の並び・新しい順・古い順・名前順・いいねが多い順・いいねが少ない順。固定ポイントは「近い順」（今いる場所から近い順）も選べます。選んだ並びは次も同じになります
ドラッグで並び替え並び替えで「自分の並び」を選ぶと、各行の左に「≡」が出ます。≡を押したまま動かし、行の上側・下側に落とすとその位置へ、フォルダの真ん中に落とすとそのフォルダの中へ移ります。フォルダごと別のフォルダに入れることもできます
まとめて操作「☑ 選択」を押すと、各行にチェック欄が出ます。選んだものを、まとめてフォルダへ移動・公開範囲を変更・削除できます。操作した後も選んだままなので、続けて別の操作ができます。終わったら「✓ 完了」を押します。選択中もフォルダを開いて中のものを選べます
フォルダの開閉開いたり閉じたりした状態は、移動や並び替えをしても変わらず、次に開いた時も同じ状態です

削除したものは元に戻せません。まとめて削除する時は、確認が出てから消えます。

5. 写真の表示

固定ポイントの写真を、地図の上にも小さく表示できます。保存している写真を縮めて出すだけなので、表示しても保存できる枚数は減りません。

🗺️ボタン →「写真」地図に写真を「出さない／ルート上の写真だけ出す／全部の写真を出す」から選べます
到達したら写真を出すルート再生・録画・ナビの時に、ポイントにさしかかったところで写真がポンと現れて残ります（🗺️ボタンの「写真」欄、または再生バーの「写真を出す」）。ナビでは次のポイントの約150m手前で出ます
この写真だけ常に出すマイリストの固定ポイントの「⋯」→「🖼 写真を地図に常に出す」で、選んだ固定ポイントの写真だけを常に表示できます

地図の写真を押すと、大きな写真で見られます。他の人のルートを見る時も、同じ設定で写真が出ます（見る権限がある写真だけ）。

6. 保存と公開範囲

ルートと固定ポイントには、3つの公開範囲があります。

🔒 非公開自分だけが見られます（初期値）
👥 フォロワー承認したフォロワーだけが見られます
🌐 公開すべての人が見られます

フォルダにも公開範囲があり、フォルダが非公開なら中身も見えません（厳しい方が優先されます）。

上書き保存と別名で保存

  • 保存したルートを開いて直した時は、「上書き保存」（同じルートを更新）と「別名で保存」（新しいルートとして保存）を選べます
  • 同じフォルダに同じ名前のルートがある時は、「上書きしますか？」と確認が出ます
  • 保存先のフォルダと公開範囲は、前回選んだものが最初から選ばれています

7. 他の人のルートを使う

  1. 「👥 フォロー」を開きます。「フォロー中」「フォロワー」に人が並びます。それ以外の人は「検索」でユーザー名から探します
  2. 並び順は、いいねが多い順（合計・ルート・固定ポイント）・更新が新しい順・名前順から選べます。名前の下に、ルートと固定ポイントの数、いいねの合計が出ます
  3. 名前を押すと、その人のページが開きます。「ルート」「固定ポイント」を切り替えて、公開・フォロワーに公開しているものを見られます
  4. ルートやフォルダをタップすると、地図に水色で表示されます。自分の作業中のルートには影響しません。「一覧に戻る」でその人のページに戻ります
  5. 中身を確認してから「保存」を押すと、自分のものとしてコピーされます（必ず非公開で保存されます）

同じ場所に自分の固定ポイントがある場合は、上書きするか、両方残すかを選べます。

ルートの中の固定ポイントのうち、持ち主が非公開にしているものは、普通のルートのピンとして表示・保存されます。保存する時に固定ポイントの空きが足りない場合は、「ルートだけ保存する」か「保存をやめる」かを選べます。保存したルートは、そのまま地図に表示されます（フォルダごとの時は最初のルート）。

通報とブロック

  • 通報：人のページの「⋯」→「このユーザーを通報」、または地図に水色で出したルート・固定ポイントの「⚠」。理由を選んで送ると、運営者が確認します
  • ブロック：人のページの「⋯」→「ブロック」。お互いのルート・固定ポイントが見えなくなり、フォローも解除されます
  • ブロックの解除：ユーザー名のボタン → 設定画面の「ブロック中の人」

8. SNS に共有する

マイリストの「⋯」→「📤 共有」（固定ポイントは編集画面の「📤 共有」でも可）で、共有の画面が開きます。ルートや固定ポイントごとに、共有用の画像が作られます。

アプリで共有LINE・X など、端末にあるアプリを選んで送ります
画像で共有画像として共有します（Instagram など）。PC では画像を保存します
リンクをコピー共有用のアドレス（https://share.thkilroy.com/〜）をコピーします
X・LINE・Facebookそれぞれの投稿画面を開きます

SNS に出る内容

🌐 公開・👥 フォロワー名前、画像（ルートの形・番号、または固定ポイントのピン・写真と、背景の地図）、持ち主のユーザー名、ポイントの数
🔒 非公開共通の画像とタイトルだけ。名前は出ません。リンクを開けるのも自分だけです

メモ、ポイントの名前は SNS に出しません。画像の背景の地図には、地図の出典（OpenFreeMap / OpenStreetMap）が小さく入ります。

リンクを開いた人は、中身を見てから保存できます。フォロワー限定のものを開いた時は、フォロー申請を送るかを聞かれます。ログインしていない時はログイン画面が出て、ログインすると自動でそのリンクが開き直されます。

9. ルート再生

🗺️ボタン →「▶ ルート再生」で、ルートをスタート地点から再生できます。開いた時は止まっているので、▶で始めます。

  • シークバー：好きな位置へ動かせます。再生中でも、止めた状態でも操作できます
  • 速度：1倍（秒速100m）から64倍まで。長いドライブなら32〜64倍で1分前後に収まります
  • 線の出し方：通った分だけ残す、全体を薄く出しておく、など
  • 追いかける・向きを回す・ピンを出す：地図の動き方とアイコンの表示を選べます
  • 写真を出す：ポイントにさしかかったところで、そのポイントの写真が現れて残ります

地図の見た目も変えられます（🗺️ボタンの「地図の見た目」でモノクロ・ダーク・ナイト、「文字とマーク」で全部表示・地名と道路名と駅名だけ・全部消す）。再生は何度でも無料です。

10. 録画（🎬）

再生バーの🎬で、ボタン類を消して地図とルートだけの画面にし、そのまま動画として保存できます。

  1. 🎬を押す → 画面共有（録画）の確認が出るので許可します
  2. 再生画面に戻り、🎬が赤くなります。この間に速度・線の出し方・スタート位置を決めます（まだ録画されていません）
  3. もう一度🎬を押すと、ボタン類が消えて録画が始まり、1秒置いてから再生が始まります
  4. 画面をタップするか、最後まで再生すると録画が終わり、保存した場所が表示されます
Android アプリ版アプリの中で録画できます。保存先は「動画（Movies）/MICHI-SHIRUBE」。📁で変更できます
PC（Chrome・Edge）ブラウザの中で録画できます。📁で保存先フォルダを選べます。選ばない時はダウンロードフォルダに保存されます
PC（その他のブラウザ）録画できます。保存先はダウンロードフォルダです
スマホのブラウザブラウザに録画の機能がないため、アプリ内では録画できません。🎬で画面を整え、端末の画面録画機能で撮影してください

録画には回数の決まりがあります（無料はアプリ版で広告動画を見ると1日3回まで）。詳しくは無料と有料をご覧ください。

作った動画を SNS などで公開する時は、地図の右下・左下に出る著作権表示（Google など）を消したり隠したりしないでください。

11. 地図の向きと現在位置

方位ボタン（赤と白の針）ズームボタンの下にあります。押すたびに「北が上で固定」と「スマホの向きに合わせて地図が回る」が切り替わります（回っている時はオレンジの枠）。針は常に北を指します。ナビ中・ルート作成中・閲覧中でも切り替えられます
現在位置ボタン（◎）押すと現在地へ移動し、そのまま現在地を追いかけます（オレンジ色）。地図を指で動かすと追いかけは止まります。追いかけ中に編集モードでもう一度押すと、今いる場所にポイントを追加できます

地図が回っている時は、地図の文字も一緒に傾きます。PC はスマホの向きが分からないため、北が上で固定です。iPhone は最初に方位センサーの許可を求められます。

  • スマホを横にした時：画面の上が向いている方角に合わせて回ります
  • 走っている時：時速約7km以上で動いている時は、スマホの向きではなく、GPS で分かる進行方向に合わせて回ります。止まるとスマホの向きに戻ります
  • 現在地を追いかけている時：現在地を画面の真ん中に保ったまま、地図がなめらかに回り、流れます

現在地が取れない時

画面左上の表示が赤くなり、「位置情報が未許可」「位置が取れません」「GPS時間切れ」のどれかが出ます。その表示か◎ボタンを押すと、使っている端末（iPhone・Android・LINE の中・PC）に合わせた直し方が出ます。設定を直したら「もう一度試す」を押してください。

12. 画面の見方

  • 最初の案内：初めて開いた時に、使い方の案内が4枚出ます（「スキップ」で閉じられます）
  • パネル：画面の下（横向きの時は右）に出る操作用の領域です
  • メニュー：パネルの中の、検索とボタンが並んでいる部分です
  • ルートリスト：ポイントが順番に並ぶ一覧です
  • ハンドル：パネルの一番上にある帯です。タップするか、しまう方向（縦向きは下、横向きは右）へスワイプすると、パネルが「メニューを隠す → 全部隠す」の順に畳まれます。隠れている時は画面の端にバーが出るので、タップするか逆方向へスワイプすると戻ります

13. アカウント

  • 新規登録：ユーザー名・メールアドレス・パスワードを入れると、そのメールアドレスに6桁の認証番号が届きます（送り主：MICHI-SHIRUBE）。10分以内に入力すると登録が終わります。届かない時は、迷惑メールのフォルダも見てください。「認証番号をもう一度送る」で送り直せます
  • 設定の引き継ぎ：地図の見た目・線の色・再生の設定・言語などは、アカウントに保存されます。別の端末でログインしても同じ設定で使えます。ログアウトすると、その端末はログインしていない時の設定に戻ります
  • アカウントの削除：ユーザー名のボタン → 設定画面の一番下の「アカウントを削除」。保存したデータはすべて消え、元に戻せません（詳しく）

14. ホーム画面に置く

  • iPhone：Safariで開く → 共有 → 「ホーム画面に追加」
  • Android：Chromeで開く → メニュー → 「アプリをインストール」

全画面で起動し、アプリのように使えます。
