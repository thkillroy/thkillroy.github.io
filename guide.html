MICHI-SHIRUBE の使い方

ブラウザで開くだけで使えます。インストールは要りません。ルートを保存したり、他の人と共有したりする時だけ、アカウント登録が必要です。

1. ルートを作る

  1. 「✏️ 編集」を押して編集モードにします
  2. 地図をタップすると、その場所がポイントとして追加されます。名前とメモを入れられます
  3. 上の検索欄から店名や住所で探して追加することもできます
  4. ポイントとポイントの間の行をタップすると、移動手段（🚗車・🚶徒歩・🚲自転車・📏直線・🚃電車・✈️飛行機）と線の色を選べます
  5. 番号と番号の間の「＋」を押すと、途中に割り込ませられます。ポイントはドラッグで動かせます

編集モードを切ると、地図をドラッグしてもポイントは動きません。ポイントをタップすると、名前とメモだけが表示されます。

2. ナビを使う

  1. 「▶ ナビ開始」を押します
  2. 次のポイントの名前・メモ・残り距離が画面上部に出ます
  3. ポイントに近づくと自動で次へ進み、音声で読み上げます
  4. ナビ中は画面が消えないようになります（対応端末のみ）

「🔄 復路」を押すと、順番が逆になった帰り道のルートになります。移動手段と線の色もそのまま引き継がれます。

3. 固定ポイント

よく行く場所は「固定ポイント」として保存できます。ルートとは別に、地図に常に表示されます。

  • 地図をタップ →「⭐ 固定ポイント」を選んで保存
  • アイコンは51種類。⭐と🚩は色も選べます
  • 「ルート番号を付ける」にチェックすると、そのまま今のルートにも組み込まれます
  • フォルダで整理できます。フォルダ単位で地図から隠すこともできます

4. 保存と公開範囲

ルートと固定ポイントには、3つの公開範囲があります。

🔒 非公開自分だけが見られます（初期値）
👥 フォロワー承認したフォロワーだけが見られます
🌐 公開すべての人が見られます

フォルダにも公開範囲があり、フォルダが非公開なら中身も見えません（厳しい方が優先されます）。

5. 他の人のルートを使う

  1. 「📂 マイリスト」→「みんな」タブを開きます
  2. フォロー中の人が並びます。それ以外はユーザー名で検索します
  3. ルートやフォルダをタップすると、地図に水色で表示されます。自分の作業中のルートには影響しません
  4. 中身を確認してから「保存」を押すと、自分のものとしてコピーされます（必ず非公開で保存されます）

同じ場所に自分の固定ポイントがある場合は、上書きするか、両方残すかを選べます。

6. 共有リンク

マイリストの「⋯」→「🔗 リンク」でURLをコピーできます。そのURLを開いた人は、中身を見てから保存できます。公開範囲は守られるので、非公開のものは他の人には開けません。

7. ルート再生（動画向け）

🗺️ボタン →「▶ ルート再生」で、ルートの線が出発地点から順に伸びていきます。速度、線の出し方、地図を追いかけるかどうかを選べます。画面録画すれば、そのまま動画素材になります。

地図の見た目も変えられます（モノクロ・ダーク・ナイト、文字や店の表示を消す）。

8. ホーム画面に置く

  • iPhone：Safariで開く → 共有 → 「ホーム画面に追加」
  • Android：Chromeで開く → メニュー → 「アプリをインストール」

全画面で起動し、アプリのように使えます。
